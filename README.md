# ribbons

A clean-room, from-scratch re-implementation of the idea behind **[lynzrand/ribbons](https://github.com/lynzrand/ribbons)** by [@lynzrand](https://github.com/lynzrand). The original project had no open-source licence, so no code or assets were copied: only the concept (and its public description) was used as inspiration. All code and assets in this repository are original.
